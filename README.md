# Aaron Crutchfield's Workshop

Practical skills, focused examples, and templates for building dependable software with AI.

Real builds. Clear explanations. Workflows you can repeat.

## Start here

### [Codex Images](skills/codex-images/)

Generate or edit an image from Claude Code using Codex CLI, then place the result in your project. Self-contained: no other toolkit skills or plugins required.

[See the examples and setup](skills/codex-images/README.md).

## How this workshop is organized

- **skills/**: independently usable agent skills, each with its own instructions and supporting files.
- **templates/**: reusable starting points, including the [resource README template](templates/Resource-README.md).
- Small runnable examples live with the resource they demonstrate. Larger applications will have their own repositories, linked here, so you can clone just the application.

Link directly to a resource folder when sharing a specific tutorial. This homepage is the catalog.

## Reuse and contribute

Skills and scripts are MIT licensed. See [LICENSE](LICENSE). Generated demonstration images illustrate the workflow; they are not promises of an identical result. Open an issue with your environment, the command you ran, and a redacted error. Do not include credentials, private prompts, or account logs.

Each resource documents its tested environment. Tool behavior can change; check the verification notes before relying on a workflow.
