# Give direction, not a pile of adjectives

State the intended use, subject, composition, background, and treatment. Use only details that affect the result. For a photograph, name a plausible light source and viewpoint. For a diagram or graphic, prioritize hierarchy, spacing, labels, and contrast instead of camera jargon.

Spell out required text in quotes. State aspect ratio and desired dimensions, then inspect the actual output: a request is not a guarantee. Keep exact production typography editable in a design tool when needed.

For edits: say what stays fixed, then specify the change. Attach the source. Avoid redescribing the entire scene when changing one object. Review the result for unwanted changes.

For a set: reuse the same palette, lighting, and style description; vary the subject or teaching point deliberately. Generate one image at a time with this wrapper.

Example: "A simple orange ceramic mug on a charcoal desk, soft window light from the left, eye-level view, uncluttered composition. No lettering. Editorial product photograph."

Edit: "Preserve the mug shape, handle, camera angle, lighting, and background. Change only the mug glaze from orange to cobalt blue."

Start with a focused prompt. When the result misses, revise the failing detail rather than adding generic phrases such as 'masterpiece' or '8K'.
